# Pull Request Template

## Summary
Describe the change, the problem it solves, and the business or technical context.

## Screenshots
Add screenshots or recordings for UI changes when relevant.

## Testing
List the tests and validation performed.

## Checklist
- [ ] Code compiles or builds locally.
- [ ] Tests were added or updated.
- [ ] Documentation was updated where needed.
- [ ] Security and performance impact reviewed.
- [ ] Rollback plan considered.

## Risk
Describe the level of risk and any known limitations.

## Reviewer Notes
Call out specific areas that need extra attention from reviewers.
